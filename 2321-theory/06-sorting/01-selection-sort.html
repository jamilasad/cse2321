Section 3

Finding the smallest: MIN

⏱ 8 min

Every pass needs one job done: find where the smallest value is. The textbook writes that job as a sub-algorithm, MIN(A, K, N, LOC).

  • It looks at A[K] to A[N] only.
  • It puts the position of the smallest in LOC.
  • It ends with Return, not Exit, like every sub-algorithm.
Your turn

Run MIN(A, 1, 7, LOC) on 2419542311733. LOC starts at 1. How many times does LOC change?

Twice. LOC = 2 when it meets 19, then LOC = 3 when it meets 5. Nothing after 5 is smaller, so MIN returns LOC = 3.

Section 6
The cost, and why there is no best case

    ⏱ 9 min
  


  

    
FinalAutumn 2023 · Q3 (a)5 marks

    
What do you mean by the complexity of algorithms? Analysis the complexity of selection sort algorithm.

  


  

    
Your turn

    

      
Seven values that are already sorted. How many comparisons? How many exchanges?

    

    
    

      
21 comparisons, 0 exchanges. MIN still has to look at every remaining value. It cannot know they are sorted without looking.

    

  


  
Pass K gives MIN the values A[K] to A[N]. MIN compares A[K] with the other N − K, so pass K makes N − K comparisons.


  

    
Pass K123456Total, n = 7

    
Comparisons65432121

  


  
Add them: (n − 1) + (n − 2) + … + 1 = n(n − 1)/2. It is the same sum as bubble sort's C. The values never change it, so the best, average and worst cases are all the same.


  

    
Time · every case
O(n²)

    
Exchanges
O(n)

    
Every pass scans the whole unsorted part: n(n−1)/2 comparisons, always. Each pass swaps at most once: never more than n − 1 exchanges. Space is O(1), one TEMP.

  


  

    
Check yourself — 4 of 6

    
Selection sort on 10 values. How many comparisons?

    

      
      
      
      
    

    
45 = 10 × 9 / 2. 100 is n². 9 is the number of passes. 55 is n(n+1)/2: pass 1 makes n − 1 comparisons, not n.

  


  

    
Check yourself — 5 of 6

    
What is selection sort's best case?

    

      
      
      
      
    

    
O(n²). Sorted input still costs n(n−1)/2 comparisons. O(n) belongs to bubble sort with the flag, which stops after one clean pass. Selection sort has no such exit.

The sentence to write

Stable

    
A sort is stable if equal values come out in the order they went in. This matters when values carry something with them. Sort a class list by mark when it is already in name order: a stable sort keeps the names in order within each mark. Selection sort may not.

Question and answer
Complexity

  

    
FinalAutumn 2023 · Q3 (a)5 marks

    
What do you mean by the complexity of algorithms? Analysis the complexity of selection sort algorithm.

  

  
Complexity. The complexity of an algorithm is a function f(n) of the input size n. It gives the running time, the storage space, or both. Time is measured by counting the key operations; in a sort, the comparisons.

  
It is discussed in cases. The worst case is the input that makes f(n) largest. The average case is its expected value. The best case is the input that makes f(n) smallest.

  
Selection sort. Pass K calls MIN on A[K], …, A[N], which makes N − K comparisons. So

  
f(n) = (n − 1) + (n − 2) + … + 2 + 1 = n(n − 1)/2 = O(n²)

  
The count does not depend on the order of the data. So the worst case and the average case are both n(n−1)/2 = O(n²), and so is the best case. There are at most n − 1 interchanges, one per pass. The extra space is one variable, TEMP: O(1).

FinalSpring 2025 · Q3 (b)1 mark
