Question and answer
G(N), defined recursively

  

    
FinalAutumn 2024 · Q2 (c)4 marks

    
G(N) = 3*X if N < 5; G(N) = 2 * G(N-3) + X otherwise. i) Find the base criteria of G. ii) Find G(2), G(8) and G(24).

  

  
i) Base criteria: N < 5. Then G(N) = 3X, with no further call.

  
ii) G(2) = 3X, because 2 < 5.

  
G(8) = 2·G(5) + X; G(5) = 2·G(2) + X = 2·3X + X = 7X; so G(8) = 2·7X + X = 15X.

  
G(24) unfolds through G(21), G(18), G(15), G(12), G(9), G(6) to G(3) = 3X. Back up: G(6) = 7X, G(9) = 15X, G(12) = 31X, G(15) = 63X, G(18) = 127X, G(21) = 255X, G(24) = 511X.

  
Put your own X in at the end. For X = 7: G(2) = 21, G(8) = 105, G(24) = 3577.






  
Question and answer
Y(K): a sum defined recursively

  

    
FinalAutumn 2022 · Q1 (a)2 marks

    
Let B be an integer array with N elements. Suppose Y is an integer function defined by Y(K) = Y(B,N,K) = 0 if K = 0; Y(K−1) + B(K) if 0 < K ≤ N; Y(K−1) if K > N. Find Y(5) for each of the following array: i. N=8, B: 3, 7, -2, 5, 6, -4, 2, 7 ii. N=3, B: 2, 7, -4

  

  
i) Y(5) = Y(4) + B(5) = Y(3) + B(4) + B(5) = … = B(1) + B(2) + B(3) + B(4) + B(5) = 3 + 7 − 2 + 5 + 6 = 19.

  
ii) K = 5 and K = 4 are both greater than N = 3, so Y(5) = Y(4) = Y(3). Then Y(3) = 2 + 7 − 4 = 5. Y(K) is the sum of the first K numbers, and it stops adding at N.






  
Question and answer
T(n), F(n) and F(8)

  

    
FinalAutumn 2025 · Q2 (c)2 marks

    
A recursive function is defined as follows: T(n) = 1, if n = 0; T(n) = n × T(n − 1), if n > 0. (i) Identify the mathematical function represented by T(n). (ii) Compute the value of T(4). [OR] A function F(n) is defined recursively: F(n) = 0, if n = 0; F(n) = F(n / 2) + 1, if n > 0. Find the value of F(8).

  

  
T(n) is the factorial, n!. T(4) = 4 × T(3) = 4 × 3 × T(2) = 4 × 3 × 2 × T(1) = 4 × 3 × 2 × 1 × T(0) = 24.

  
F(8) = F(4) + 1 = F(2) + 2 = F(1) + 3 = F(0) + 4 = 4. (n / 2 is integer division, so F(1) calls F(0).)






  
Question and answer
A Fibonacci-shaped F(n)

  

    
FinalSpring 2025 · Q2 (c)3 marks

    
Consider a recursive function: int F(int n) { if (n <= 3) return 2 * n; return F(n - 1) + F(n - 2); } i) What is the base case? ii) Calculate F(2) and F(5). iii) What type of problem does this recursion model?

  

  
i) n ≤ 3, where F(n) = 2n with no call.

  
ii) F(2) = 2 × 2 = 4. F(5) = F(4) + F(3) = (F(3) + F(2)) + F(3) = (6 + 4) + 6 = 16.

  
iii) Each value is the sum of the two before it: a Fibonacci-like sequence. Each call makes two calls, so it draws a tree, like fib in Section 4.
