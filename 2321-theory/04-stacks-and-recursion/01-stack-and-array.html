Section 1

A pile you touch only at the top

⏱ 5 min

You already use stacks every day.

A pile of bowlsA clean bowl goes on top. You take the top one.
Socks and shoesSocks go on first. They come off last.
Bangles on a wristThe last bangle on is the first one off.
A tennis-ball tubeOnly the top ball can come out.
Your turn

In Segment 1 you pressed Undo several times. Which item did Undo take back first?

The last one typed. That is what makes Undo a stack.

Definition

A stack is a list of elements in which an element may be inserted or deleted only at one end, called the top of the stack. Stacks are also called last-in first-out (LIFO) lists.

  • push inserts an element on the top.
  • pop deletes the element on the top.
  • top reads the element on the top, without removing it.

Overflow and underflow

    ⏱ 10 min
  


  

    
Your turn

    
The array has 5 cells and holds 5 items. Push a sixth. What happens?

    
    
topIdx becomes 5, and push writes arr[5], one past the end. C++ does not check, so the value goes over whatever is next in memory. The other end is the same: a pop on an empty stack makes topIdx = -2, and the next push writes arr[-1].

The two tests

    
push first asks topIdx == N - 1: is the top already in the last cell? If so, it prints Overflow and returns.

    
pop first asks topIdx == -1: is the stack empty? If so, it prints Underflow and returns.

  


  

    
Check yourself — 4 of 5

    
With N = 5, which test goes at the start of push?

    

      
      
      
    

    
topIdx == N - 1. The last cell is arr[4]. When topIdx is already 4, there is no room. topIdx == N would let a sixth push write arr[5] first.

Model answers
What to write


  
What is a stack?

  
A stack is a list of elements in which an element may be inserted or deleted only at one end, called the top of the stack. Stacks are also called last-in first-out (LIFO) lists.

  
The two basic operations. PUSH inserts an element into a stack, on the top. POP deletes the top element from a stack.

  
Two applications you have met: undo and redo in an editor, which uses two stacks, and function calls, where each call is a frame pushed on the call stack and popped when it returns.


  
Array representation

  
A stack is maintained by a linear array STACK, a pointer variable TOP, which contains the location of the top element of the stack, and a variable MAXSTK, which gives the maximum number of elements that can be held by the stack. The condition TOP = 0 indicates that the stack is empty. For example, if TOP = 3 and MAXSTK = 8, the stack holds three elements, and five more can be added.

Reverse a stack

  
Pouring a stack into another reverses it. Pour three times, and the original stack ends up reversed.
