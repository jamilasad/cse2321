Five students sit in a row. The last one is asked: “How many people are in front of you?” He asks the one in front, hears 3, and says 4.

He never counts the row. He does not know how the 3 was worked out. He trusts the reply and adds 1.

That reply is the magical function: a function that already gives the right answer for a smaller input. You may use it without looking inside.

The two properties of a recursive procedure

    
Lipschutz states them like this. Autumn 2023 Q1(a) asks for them word for word.

    
    
      
  1. There must be certain criteria, called base criteria, for which the procedure does not call itself.
    2. 
      
  2. Each time the procedure does call itself, it must be closer to the base criteria.
    3. 
    

  


  

    
Your turn

    
H(N) = 3N if N < 5, and H(N) = 2·H(N − 5) + 7 otherwise. What is the base criteria?

    
    
N < 5. There, H(N) = 3N with no call. Every other call is on N − 5, which is closer to it.

  


  

    
Check yourself — 2 of 5

    
What are the two properties of a recursive procedure?

    

      
      
      
    

    
A base criteria, and each call closer to it. Without the first it never stops. Without the second it never reaches the stop.

There is no stop yet. Trace the general line down from fib(2). Where does it break?

    
    

      
fib(2) needs fib(1) and fib(0). fib(1) needs fib(0) and fib(−1), and fib(0) needs fib(−1) too. There is no fib(−1), so it breaks there.

Name it: sum(a, n) gives the sum of the first n numbers of a. Play on a = {4, 7, 1, 5}:

  

  
The cut is the last number. Trust the first n − 1, then use it: add a[n − 1].

  

  
The stop: sum(a, 0) would call sum(a, −1), which makes no sense. So sum(a, 0) answers by itself: no numbers add up to 0.

3n + 1, counted

    ⏱ 6 min
  


  
Recursion 1 printed the 3n + 1 sequence. This exam question counts it:

  

    
FinalSpring 2026 · Q2 (c) [OR]3 marks

    
Consider a recursive function tracking the cycle steps of the 3n + 1 problem: int collatz_steps(int n) { if (n == 1) return 1; if (n % 2 == 0) return 1 + collatz_steps(n / 2); else return 1 + collatz_steps(3 * n + 1); } Manually trace the step-by-step execution states and calculate the exact return value of collatz_steps(7).

  

  
Build it in four steps. Name it: collatz_steps(n) gives how many numbers the sequence visits, from n down to 1. Play:

  

  
The cut is the next term m. Trust collatz_steps(m), then use it: add 1 for n itself. The stop is n == 1, which counts the 1.

  

  
It is the exam’s function, unfolded into four steps. collatz_steps(7) visits 7, 22, 11, 34, 17, 52, 26, 13, 40, 20, 10, 5, 16, 8, 4, 2, 1. That is 17.

  
One honest note. The next term can be bigger: 7 goes to 22. Nobody has proved that every start reaches 1. It is a famous open problem, checked by computer for every start up to enormous numbers.

Section 9
GCD: two inputs shrink

    ⏱ 6 min
  


  
The exam defines GCD(A, B) like this:

  
    
    
  • GCD(B, A) if A < B
    • 
    
  • A if B = 0
    • 
    
  • GCD(B, MOD(A, B)) otherwise
    • 
  

  

  
The first rule only swaps the inputs, so the bigger one comes first. The stop is B = 0. The trust is GCD(B, A mod B): both inputs shrink, because A mod B is always smaller than B.

  

    (540, 279)→(279, 261)→(261, 18)→(18, 9)→(9, 0)→9
  

  
GCD(540, 279) takes 5 calls to reach the stop. The answer is A at the stop: 9.

  


  

    
Your turn

    
Work out GCD(20, 28) by the exam’s definition.

    
    
4. 20 < 28, so swap: GCD(28, 20). Then GCD(20, 8), GCD(8, 4), GCD(4, 0) = 4.

  


  

    
Your turn

    
Spring 2023 also asks: what does this function do? Compare the answer 9 with 540 and 279.

    
    
It finds the greatest common divisor of A and B: the biggest number that divides both. 9 divides 540 and 279. 4 divides 20 and 28. This is Euclid’s algorithm.

What is GCD(6, 15)?

    

      
      
      
    

    
3. GCD(6, 15) swaps to GCD(15, 6), then GCD(6, 3), then GCD(3, 0) = 3.

Question and answer
The two properties, and three base criteria

  

    
FinalAutumn 2023 · Q1 (a)3 marks

    
Write the two properties of a recursion function. Find the base criteria of the following recursive functions: i. H(N) = 3*N if N < 5, 2*H(N−5)+7 otherwise; ii. F(N) = 1 if N = 0, N.F(N−1) if N > 0; iii. GCD(A,B) = GCD(B,A) if A < B, A if B = 0, GCD(B, MOD(A,B)) otherwise.

  

  
The two properties.

  
    
    
  1. There must be certain criteria, called base criteria, for which the procedure does not call itself.
    2. 
    
  2. Each time the procedure does call itself (directly or indirectly), it must be closer to the base criteria.
    3. 
  

  
For a recursive function Lipschutz says base values: certain arguments for which the function does not refer to itself, and each time it does refer to itself, the argument must be closer to a base value.

  
i) H: N < 5. Then H(N) = 3N, with no call.

  
ii) F: N = 0. Then F(0) = 1, with no call. F is the factorial.

  
iii) GCD: B = 0. Then GCD(A, 0) = A, with no call. A < B is not a base criteria: it still calls GCD(B, A).
